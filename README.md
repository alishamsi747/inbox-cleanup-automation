# inbox-cleanup-automation
Developed Python script to automate email archiving and deletion, saving over 10 hours per month on manual inbox management
Python script using `imaplib` to automatically find and delete emails older than a specified date

## Tech
Python 3, `imaplib`, `email`

## Note
Gmail requires an App Password (not your regular account password) for IMAP access when 2FA is enabled. Generate one in your Google Account security settings.
